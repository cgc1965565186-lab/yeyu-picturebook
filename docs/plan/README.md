## 素材为什么不进仓库

`素材/绘本素材/` 下是官方比赛用书与音频（约 300 MB，且属授权材料），按 V2.1 §21.5、§30.3
"受限素材不进入公开代码"的要求，默认由 `.gitignore` 排除。文件本身就在本目录，
不会丢失；换机器时按下面的方式恢复并校验。

```bash
# 从原始压缩包恢复
unzip -O gbk "纸书智伴企业预选赛绘本素材.zip" -d 素材/
# 校验完整性（对比 清单/素材清单.csv 的 SHA-256）
python3 scripts/verify_assets.py --root docs/plan
```

需要强制入库时，删除 `.gitignore` 中 `素材/绘本素材/**/*.pdf` 与 `*.wav` 两行即可。
