## 2. 挂机期间必须有的三样东西

异步生成最大的风险不是慢，是**失败了没人知道**——而且是**静默失败**：余额不足、鉴权错、参数被拒，这些都不会自己好，你回来只会看到 6 小时前就 401 了。

笔记本带去上课的话，风险从"没人看"变成"机器睡了"：

```bash
# 合盖前先跑这个，阻止睡眠（Ctrl-C 或关终端即恢复）
caffeinate -dimsu
```

| 变量 | 会怎样 | 对策 |
|---|---|---|
| 合盖睡眠 | 进程挂起，轮询停摆 | `caffeinate -dimsu`，或系统设置里开"电源适配器时防止自动睡眠" |
| 换教室断 Wi-Fi | 连接中断，下一次轮询报错 | 轮询失败只计数不退出；恢复网络后自动续上（`watch` 已内置） |
| 电量 | 跑到一半关机 | 带电源；`caffeinate -u` 不阻止电池耗尽 |
| 静默失败 | 401/余额不足/参数错，重试也没用 | **必须告警**，人的在场只加快处理，不能替代告警 |

| 需要 | 最小实现 | 为什么不能省 |
|---|---|---|
| **状态落盘** | 每个任务写 `task_id, status, updated_at` 到 `var/video_tasks.json` | 合盖/重启/切网后还能接着查 |
| **告警** | 轮询发现 `failed` 或超时 → `osascript` 弹通知 + stderr 红字 | 静默失败时唯一能叫醒你的东西 |
| **幂等** | 创建前按 `business_id` 查账本；`submission_unknown` 只查询不重建 | 手一抖重复提交 = 双倍扣费 |

三样都在 `scripts/minimax_video.py` 里实现了：

```bash
export MINIMAX_API_KEY=sk-...
python scripts/minimax_video.py submit --business-id CN01-S01 --prompt "..." --duration 6 --dry-run  # 先看请求体
python scripts/minimax_video.py submit --business-id CN01-S01 --prompt "..."                      # 真提交
python scripts/minimax_video.py watch --max-cny 320 --deadline-hours 10                            # 挂机 + 熔断 + 告警
```

```bash
# 最小的失败提醒（macOS，可放在轮询循环里）
osascript -e 'display notification "生成任务失败：CN01-S03" with title "页语" sound name "Basso"'
```
