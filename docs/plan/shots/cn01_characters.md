# CN01《一起搭积木吧》角色与风格规范

> 来源：逐页读图核对（pages/CN01，12 页）。所有生成镜头以此为准，禁止模型自由发挥。

## 角色

| 角色 | 外观（不可变） |
|---|---|
| **花花** | 黑发，侧扎马尾、系粉色蝴蝶结，额前两朵小红花发卡；粉色短袖 T 恤（胸前一朵小黄花），粉白相间竖条纹短裤，白袜粉鞋；脸圆、腮红重 |
| **小满** | 黑发，头顶双丸子（冲天小辫），红色蘑菇图案发卡；白色 T 恤 + 红色瓢虫图案背心式背带裤，红鞋 |
| **黄米团** | 黄色小狗，背上有深褐色斑块，红色项圈，尖立耳，尾巴上翘 |

两个都是**女孩**（早期版本误记为男孩，已纠正）。

## 画风

水彩 + 彩铅质感，暖色调，粗圆线条勾边，人物"头大身小"（约 1:2.5），
腮红明显，背景大量留白；不出现任何印刷文字、字幕或水印。

## 场景

- 室内：浅绿木地板/绿色地垫、白墙、右侧大窗（浅蓝窗帘）、木质矮柜
- 室外：绿色草坡、白花、矮树、门口台阶与盆栽
- 反复出现的道具：彩色木质积木（红/黄/绿/蓝/粉/紫）、相框（两人合影）、气球、生日蛋糕（写"花花：生日快乐！"）
